### ⚡ Despliegue Rápido

```bash
# Opción 1: Cloud Run (Recomendado)
chmod +x deploy-cloudrun.sh
./deploy-cloudrun.sh

# Opción 2: App Engine
chmod +x deploy-appengine.sh
./deploy-appengine.sh

# Configurar Base de Datos
chmod +x setup-database.sh
./setup-database.sh
```
